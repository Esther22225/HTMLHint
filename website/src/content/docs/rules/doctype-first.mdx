import { Badge } from '@astrojs/starlight/components';

The DOCTYPE declaration must appear before any non-comment content in an HTML document. Comments and whitespace are permitted before the DOCTYPE.
Level: <Badge text="Error" variant="danger" />

## Config value

- `true`: enable rule
- `false`: disable rule

### Valid Examples

```html
<!DOCTYPE html>
<html></html>
```

```html
<!-- Comment before doctype -->
<!DOCTYPE html>
<html></html>
```

### The following patterns are considered rule violations

```html
<html></html>
```

```html
<!-- Comment before DOCTYPE -->
<!DOCTYPE html>
<html></html>
```

### Why this rule is important

The DOCTYPE declaration is required for HTML5 compliance and to ensure that the document is parsed correctly.
